# OIBSIP Web Development & Designing – Level 1 Task 1

## Project: LearnHome Tuition Landing Page

### About the Project

This project is a responsive landing page for a home tuition service called **BrightPath LearnHome Tuition**.

The website is designed to provide information about tuition programs, services, tutors, fees, and contact options in a clean and user-friendly layout.

### Technologies Used

- HTML5
- CSS3
- JavaScript

### Features

- Responsive navigation bar
- Hero section with call-to-action buttons
- Tuition programs section
- Services section
- Why choose us section
- Saturday activities section
- Tutor section with class and subject filters
- Fee plans section
- Contact section
- Responsive design for desktop, tablet, and mobile devices
- Interactive tutor filtering using JavaScript
