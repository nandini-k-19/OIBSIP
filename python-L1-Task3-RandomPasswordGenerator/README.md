# 🔐 Random Password Generator

A secure and user-friendly random password generator built with Python and Tkinter.

## ✨ Features

- Generate secure random passwords
- Choose password length from 8 to 32 characters
- Select uppercase letters
- Select lowercase letters
- Select numbers
- Select symbols
- Exclude confusing characters
- Check password strength
- Copy password to clipboard
- Display the last 5 generated passwords
- Input validation for password length

## 🛠️ Technologies Used

- Python
- Tkinter
- Secrets
- String

## ▶️ How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder.
4. Run:

```bash
python password_generator.py
